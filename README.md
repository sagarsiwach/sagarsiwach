## Things I've built

- **[extend-addons](https://github.com/sagarsiwach/extend-addons)** — Google Workspace add-ons with Preact + Bun. Starting with form choice limiting, building toward 20 plugins.
- **[figma-sanews-plugin](https://github.com/sagarsiwach/figma-sanews-plugin)** — Figma plugin that fills newspaper layouts using Claude. Built for a weekly print workflow.
- **[bhakti-tracker-v2](https://github.com/sagarsiwach/bhakti-tracker-v2)** — Mantra and prayer tracker. Bun + SQLite + Svelte. Built because nothing else fit.
- **[invoice_parser](https://github.com/sagarsiwach/invoice_parser)** — Parses invoice PDFs. Surprisingly useful.
